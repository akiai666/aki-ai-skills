# 动作图与台词匹配

先读取用户现有动作素材，再补齐本片实际需要的动作。用 imagegen 生成独立全身图；一张一个姿势，不把小尺寸九宫格裁成所谓高清单图。脸、眼镜、发型、衣服、头身比例来自同一张身份参考。生成原图和提示词保留在私人项目中，透明 PNG 与 character.json 可单独复用。

| 语义 | 动作 | 对应画面 |
|---|---|---|
| 开场、招呼 | wave 挥手 | 配标题短暂出现，随后收势 |
| 疑问、判断 | think 托腮 | 配疑问或等待结果 |
| 解释、转折 | explain 摊手 | 手掌朝向需要注意的内容 |
| 强调、结论 | point 指向 | 手指朝向标题或关键点 |
| 展示条件 | hold 托卡 | 卡片下边缘接触手掌 |
| 输入、执行 | push 推送 | 推送瞬间卡片从手部出发 |
| 无效结果、意外 | surprise 后仰 | 双手、躯干和腿一起体现反应 |
| 成功、认可 | approve 点赞 | 在结果出现后切换 |

动作图不要求持续变形。按照“准备姿势 → 执行姿势 → 稳定停顿”切换，在动作的语义时刻换图；避免每秒机械换姿和长时间双人重影的交叉淡化。只有图上确实抬脚时才移动到另一站位，不用站立图横滑冒充走路。道具位置由对应姿势的 characterPoint() 得到，不能沿用旧站姿的手坐标。

验收须查看原始全身与脸部、手部细节：无多指/缺肢，衣服连续，身份一致，透明边缘无杂色。按脚底锚定、按头部尺度校准视觉大小，抬手时不缩小整个人。重做样片保留上一版，复用已确认的旁白和字幕。
